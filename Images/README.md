# Images/

Test images and previews used for functional verification. All generated by
`Python/prepare_stimulus.py` / `Python/mem_to_image.py` unless noted.

| File | Purpose |
|---|---|
| `input.png` | Source 32x32+ grayscale input image (checked in) |
| `input_32x32.mem` | `input.png` resized/quantized to 32x32 8-bit unsigned, `$readmemh` format — fed to `image_memory.v` |
| `input_32x32_preview.png` | Visual of exactly what the RTL processes (post-resize/quantize) |
| `rtl_output_preview.png` | RTL's captured output (`sim/rtl_output.mem`) rendered as a 30x30 PNG |
| `input_roundtrip_check.png`, `self_check.png` | Ad-hoc sanity-check snapshots from earlier manual testing |
| `kernels/` | Programmable NxN signed 8-bit kernel coefficient sets — see `kernels/README.md` |

Regenerate everything with the Quick Start flow in the root `README.md`.
