# Images/

Holds all image assets used for functional verification.

| File / Folder          | Purpose |
|-------------------------|---------|
| `input.png`              | Sample >=32x32 grayscale input image fed to both the Python golden model and the RTL testbench (via `Python/image_loader.py`). Placeholder - populate in Phase 2. |
| `expected_output.png`    | Golden-model convolution output rendered as an image, for visual sanity-checking alongside the numeric PASS/FAIL check. Generated by `Python/verify.py`. |
| `kernels/`               | Programmable kernel coefficient sets (signed 8-bit, NxN) used across test runs - e.g. `edge_3x3.txt`, `blur_3x3.txt`, `identity_3x3.txt`, `random_5x5.txt`. Loaded by `Python/image_loader.py` and `Python/image_generator.py`, and mirrored into `kernel_memory.v` init files for simulation. |

No image or kernel data has been generated yet - this stage only reserves the
location. Content is produced starting Phase 2 (Python Golden Model).
